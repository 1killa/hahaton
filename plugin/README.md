# STE Assistant — черновик 0.1

Плагин для STE Slicer 7.10 / Cura API 5. Интерфейс работает в системном браузере, Python-код — внутри слайсера. Внешние Python-пакеты и сборка JavaScript не нужны.

## Установка

1. Закройте STE Slicer.
2. Через **Справка → Показать папку конфигурации** найдите папку нужной версии. Обычно это `%APPDATA%\steslicer\7.10`.
3. Скопируйте **папку `AIAssistant` целиком** из этого каталога в `plugins` папки конфигурации. Должен получиться путь `plugins/AIAssistant/plugin.json`.
4. Перезапустите STE. Откройте **Расширения → STE Assistant → Открыть чат и настройки**. Название верхнего меню может зависеть от языка приложения.
5. В чате нажмите шестерёнку. Base URL: `https://api.timeweb.ai/v1`; модель: `dashscope/qwen3.8-flash`. Введите API key и сохраните.

В репозитории также есть `tools/install.ps1`. Скрипт устанавливает только в новый каталог, существующий плагин не перезаписывает.

Ключ хранится в preferences STE (`ste_assistant/api_key`). В исходниках ключа нет; браузеру после сохранения возвращается только признак наличия. Пустое поле сохраняет прежний ключ, флажок удаления очищает его. Каждый платный запрос инициирует пользователь; автоматических повторов после сетевой ошибки нет.

## Первый запуск

1. В STE выберите **Stereotech Hybrid 530 V5.2.4** и доступный материал.
2. Загрузите STL в STE или прикрепите STL/OBJ/3MF в чате. Для 3MF возможен штатный диалог импорта проекта — завершите его в STE.
3. Напишите: «Прочитай сцену и доступные профили. Подготовь модель к 3D-печати. Сначала объясни предлагаемые изменения». Обязательно сообщите назначение детали и материал.
4. Вызовы инструментов и фактические результаты видны в чате. Можно закрепить настройки, ID материала и сохранение размеров. Пожелания в свободном тексте имеют рекомендательный характер.
5. Попросите применить параметры и запустить слайсинг. Статус и прогресс появятся справа. После успешного нового слайсинга сохраните 3MF и экспортируйте G-code. Файлы скачиваются из панели «Файлы».
6. Откройте полученный 3MF заново и проверьте настройки, ориентацию и предпросмотр G-code в STE перед использованием.

Поддерживаются только `classic` (3D), `cylindrical` (5D Spiral), `cylindrical_full` (5D). Инструмент `check_5d` разделяет факты сцены и инженерные предположения; точная геометрия удаляемой внутренней цилиндрической области в этом черновике не вычисляется.

## Что реализовано

- Chat Completions с tool calling; PNG/JPG передаются как base64 `image_url`.
- MCP JSON-RPC `initialize`, `tools/list`, `tools/call` по `/api/mcp`. Те же инструменты используются агентом и кнопками интерфейса.
- Чтение/изменение global/extruder settings; выбор режима, профиля и материала; операции модели; запуск/статус слайсинга и нативные writers.
- Формальные жёсткие требования блокируют конфликтные вызовы. Перед слайсингом/сохранением проверяется фактическое значение закреплённых настроек и ID материала. Закрепление требования само по себе не применяет настройку.
- Сравнение 2–3 **наборов настроек** с настоящим последовательным слайсингом внутри STE; отдельные 3MF/G-code; восстановление исходных user overrides. Профили, материалы и положение модели между вариантами не меняются. Применение варианта требует нового слайсинга.
- Локальный сервер: loopback, случайный порт, токен сессии в заголовке, проверки Host/Origin, ограниченные вложения. Токен никогда не передаётся URL query; fragment убирается после открытия страницы.

## Границы проверки

На 23.10.2026 код проверяется на Python 3.5.7 из установленного STE, с локальным тестовым Chat Completions сервером и тестовыми адаптерами. Это не подтверждение реального провайдера Timeweb и полного цикла на всех моделях организаторов. Для Timeweb нужен ваш ключ; импорт/слайсинг/экспорт внутри запущенного STE требуют отдельного сквозного прогона. Отсутствующий API выдаёт ошибку, а неизвестные время/расход не заменяются вымышленными числами.

Диалог, закреплённые требования и список вариантов хранятся в памяти текущего запуска. API-настройки плагина сохраняются в STE. Удалённые через инструменты объекты и трансформации используют штатные undo operations STE.

При отмене новые agent tool calls прекращаются; уже начатый запрос к LLM может завершаться до 60 секунд. Файлы результатов сохраняются в каталоге данных STE `ste_assistant/outputs`; они доступны через панель скачивания. Вложения текущего запуска удаляются при штатной остановке помощника.
