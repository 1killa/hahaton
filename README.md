# STE Assistant — хакатон

Черновик плагина ИИ-помощника для STE Slicer 7.10 (Python 3.5, PyQt5, API 5).

Текущая версия MVP — **0.4.2**. Исправлены пять кнопок сцены нативного окна: обновление, проверка 5D, нарезка, сохранение 3MF и экспорт G-code. Результат действия показывается рядом с кнопками. Фильтр вложений включает STL по умолчанию. Браузерный интерфейс сохранён; оба окна используют общие настройки, историю и инструменты. После обновления установленного плагина сохраните проект и перезапустите STE.

В меню **Расширения → STE Assistant** доступны **«Открыть чат в STE Slicer»** и прежний пункт **«Открыть чат и настройки»** для браузера. Нативное окно позволяет работать со сценой параллельно; закрытие окна сохраняет диалог.

Подключение уже настроено на `https://api.timeweb.ai/v1`, модель `dashscope/qwen3.8-flash`. Введите свой ключ в настройках открытого чата. Ключ не нужно добавлять в файлы или Git.

В версии 0.3 можно прикреплять ТЗ в DOCX/TXT вместе с моделью, сохранять локальные диалоги и задавать условия из окна чата. Сцена и журнал разработчика находятся на отдельных вкладках. Длинная задача сохраняется на паузе и продолжается кнопкой «Продолжить».

## Посмотреть интерфейс без STE

```powershell
python dev.py
```

Откроется локальный DEMO с примером сцены. Без ключа можно проверить настройки и ручные инструменты. DEMO не выполняет слайсинг, не выдаёт метрики печати и не создаёт 3MF/G-code. Если ввести ключ, сообщения в DEMO отправляются настоящему провайдеру, но инструменты слайсера остаются демонстрационными. Ключ в этом режиме хранится только в памяти процесса.

## Проверка и упаковка

```powershell
python -m unittest discover -s tests -v
node --check plugin/AIAssistant/web/app.js
python tools/package_submission.py
```

Для проверки на установленном Python STE:

```powershell
.\tools\run_host_python.ps1 -Script .\tools\host_smoke.py
.\tools\run_host_python.ps1 -Script .\tools\host_tests.py -Log .runtime\host-tests.log
.\tools\run_host_python.ps1 -Script .\tools\host_adapter_regressions.py -Log .runtime\adapter-tests.log
.\tools\run_host_python.ps1 -Script .\tools\host_export_regression.py -Log .runtime\export-tests.log
.\tools\run_host_python.ps1 -Script .\tools\host_tls_smoke.py -Log .runtime\tls-smoke.log
```

Архив имеет требуемые верхние папки `plugin/` и `results/`. Перед сдачей добавьте фактические результаты по всем моделям и используйте `--require-results`. Репозиторий не содержит ключей и результатов, выданных за реальные без слайсинга.
