# Результаты испытаний

Сейчас здесь нет конкурсных 3MF/G-code: их необходимо получить настоящим слайсингом через плагин. Тестовые fixtures из автоматических тестов сюда не копируются.

Для каждой модели создайте отдельную папку:

```text
results/<model_name>/
  project.3mf
  result.gcode
  chat_01.png
  chat_02.png
```

Скачайте фактические результаты из чата, приведите имена к указанным выше и добавьте скриншоты диалога. Проверьте повторное открытие 3MF, режим, профиль/материал, ориентацию и предпросмотр G-code. Не используйте скриншоты standalone DEMO как доказательство печати.

Отчёт о проверке кода — `docs/VERIFICATION.md` в репозитории; обнаруженные API — `docs/API_CONTRACT.md`. Финальный архив собирается командой `python tools/package_submission.py --name <team_name> --require-results`. Без `--require-results` получается явно обозначенный черновик.
