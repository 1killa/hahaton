# Исправления 0.3.2

## Результаты слайсинга

В истории подтверждена ошибка `native slicing emitted no Processing or slicing-start evidence`. `UM.Signal` использует `WeakImmutableList`: переданные лямбда-обработчики удалялись сборщиком мусора, поэтому плагин не получал сигналы начала, прогресса и завершения нарезки. Адаптер удерживает сильные ссылки до следующего запуска и отключает старые обработчики.

После Done метрики повторно читаются из `PrintInformation`, включая обновления после постобработки. Ошибка одного поля времени не скрывает доступный расход материала. Проверен API `DurationFormat.Format.Seconds`. Native `materialLengths` измеряется в метрах, поэтому в `material_mm` теперь передаются значения, умноженные на 1000. Масса остаётся в граммах, значения сохраняются по экструдерам.

Защита от старого G-code, другой платформы и неподтверждённого завершения сохранена.

## Загрузка

Лимиты синхронизированы в браузере и HTTP-сервере: модели 64 MiB, изображения/документы 24 MiB. Размер JSON-запроса учитывает расширение base64. Проверена загрузка через HTTP бинарного STL размером 28 234 884 байта — размер конкурсной фигурки. Сохраняются ограничения числа файлов, общего объёма сессии, структуры ZIP и документов.

## Параметры

В журналах обнаружены `wall_line_count="5"`, `support_enable="true"` и аналогичные строковые значения. Адаптер преобразует только однозначные скаляры по фактическому типу нативного определения: числовые строки, целые числа без дробной части и логические true/false/yes/no/1/0. Значения с единицами, нечисловые строки, NaN и дробные количества линий отвергаются.

Нормализация выполняется до проверки закреплённых требований, поэтому ограничения не обходятся строковым представлением. Запись идёт через `InstanceContainer` userChanges. Запасной путь больше не вызывает двухаргументный `QObject.setProperty`, который создавал Qt-свойство вместо настройки печати. Успех подтверждается чтением из стека.

## Проверка

Полный suite на Python 3.5.7 STE: **111 тестов, 108 прошли, 3 пропущены** (два отсутствующих внешних DOCX-fixture и создание symlink на Windows). Native adapter regressions, импорт/компиляция всех 12 Python-модулей, HTTP/menu smoke и `node --check` — PASS. Обновлённые файлы установленного плагина сверены SHA-256, прежние сохранены в `.runtime/before-0.3.2/`.

`tools/host_adapter_regressions.py` проверяет настоящие `ContainerStack`, `InstanceContainer`, `SettingDefinition`, `UM.Signal` (в прямом режиме без приложения) и `Duration` на Python 3.5.7 STE. Реестр определений подставлен тестовый; пользовательские настройки и сцена не меняются. Сигналы проверены после сборки мусора, а время/расход — на контролируемых входных данных.

Полный рабочий слайсинг пользовательской модели в GUI в эту проверку не входит. После установки нужен перезапуск STE и новый запуск нарезки: предыдущие потерянные сигналы восстановить задним числом нельзя.
