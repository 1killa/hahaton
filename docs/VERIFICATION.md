На Windows сетевые и файловые тесты запускались вне ограниченного sandbox с временным каталогом **внутри `.runtime/` проекта**. Причина — sandbox блокирует loopback sockets и очистку своего системного TEMP; продуктовые ограничения сети не ослаблялись.

### Исправление вылета при открытии чата, 23.10.2026

В журнале установленного STE подтверждён `AttributeError: type object 'Resources' has no attribute 'DataStorage'` в `AIAssistant.showChat`. Вызов заменён на `os.path.join(Resources.getDataStoragePath(), "ste_assistant")`, соответствующий API установленной версии. Проверка `tools/host_smoke.py` дополнена вызовом пункта меню: до исправления она воспроизвела тот же `AttributeError`, после исправления прошла. Повторный полный набор на штатном Python: 34 теста, 33 прошли, один пропущен из-за недоступного создания symlink. Само окно приложения в этой проверке не запускалось.

## Что ещё не подтверждено

- Реальный ответ `https://api.timeweb.ai/v1` и поддержка инструментов/изображений моделью `dashscope/qwen3.8-flash`: пользователь пока не вводил ключ. В исходниках и отчётах настоящего ключа нет.
- Полный сценарий в запущенном STE: выбор **Stereotech Hybrid 530 V5.2.4** → загрузка выданной модели → реальные настройки/ориентация → слайсинг → повторное открытие нативного 3MF и G-code. Автотесты не заменяют этот прогон.
- Проверка всех моделей организаторов и всех трёх режимов.
- Геометрический анализ области внутри Base Diameter, прочность и качество поверхности. `check_5d` — предварительная проверка доступных фактов и предупреждений.
- Symlink regression не выполнен, поскольку ОС не дала создать ссылку; код защиты пути и атомарной записи присутствует, остальные файловые проверки прошли.

## Состояние результатов

`results/` содержит только инструкции. Настоящих конкурсных `project.3mf`, `result.gcode` и скриншотов переписки с реальным слайсингом пока нет. `docs/screenshots/demo-ui.png` и `settings.png` — исключительно скриншоты интерфейса DEMO; настоящий ключ на них отсутствует.

Черновой ZIP служит для установки и следующего прогона. Скрипт с `--require-results` отказывает, если не добавлены настоящие артефакты в требуемой структуре.

## Решения после review

- Замечания о stale G-code, пустой сцене, atomic writer, native build plate и пробельном ключе исправлены и покрыты регрессиями.
- Обычное отсутствие `scope` в закреплённом правиле трактуется как global; значение и extruder=0 явно нормализуются при сохранении. Это документированный default, аналогичный интерфейсу, а не необеспеченное требование.
- Автоповторов платных запросов нет. Demo может обращаться к реальному LLM только после ввода ключа и отправки сообщения пользователем; печать/экспорт в Demo недоступны.
