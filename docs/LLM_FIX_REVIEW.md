# Проверка подключения LLM, 24 октября 2026

Исходная версия GitHub: `29fc8fc`, плагин 0.3.0. Исправленная версия: 0.3.1.

## Сверка исходников

Все 16 исходных файлов установленного плагина сверены с актуальным репозиторием: содержание совпадало, различались переводы строк. Проверены точки регистрации, Qt bridge, конфигурация, core, MCP, registry инструментов, native adapter, HTTP-сервер, сохранение диалогов, чтение документов и SPA. Полный поведенческий suite и импорт/компиляция запускаются на Python 3.5.7 STE; JavaScript проверен через `node --check`.

В обновлённой версии снова обнаружены `stream: false`, ожидание ответа до 60 секунд и неявный HTTPS-контекст приложения. Ранее внесённые сетевые исправления отсутствовали в этой версии. Новые функции документов, истории и продолжения сохранены.

## Исправления

- `stream: true`, разбор SSE, восстановление фрагментов текста и function tool calls по индексам. Обычные JSON-ответы также поддерживаются.
- Явный SSL-контекст с системными корневыми сертификатами; проверка цепочки и hostname включена. Глобальный контекст STE не изменяется.
- Socket idle timeout — 180 секунд. Размер ответа ограничен 8 MiB, длительность активного потока проверяется между кадрами (600 секунд).
- Недочитанный поток, обрезанный ответ и `finish_reason=length` не запускают частичные инструменты.
- `ProviderTimeout` переводит существующую задачу на паузу `provider_timeout`. «Продолжить» отправляет следующий запрос с завершёнными результатами, без replay инструментов.
- Отмена проверяется при чтении SSE. Уже начатое блокирующее чтение может ожидать данные до socket timeout. Автоматических повторов нет.

## Проверки

- Исходный suite: 93 теста, 90 прошли, 3 пропущены.
- Итоговый suite на Python 3.5.7 STE: 103 теста, 100 прошли, 3 пропущены (ограничения Windows для ссылок/доступа).
- Native smoke: 12 Python-файлов, imports, регистрация, callback меню, HTTP SPA и повторное открытие — PASS в тестовом контексте приложения.
- Локальный HTTP-провайдер: поток длится дольше одного socket timeout, но кадры приходят вовремя — запрос завершается без повтора.
- SSE: UTF-8, фрагменты JSON аргументов, чередование инструментов, heartbeat, оборванный поток, лимиты, отмена — PASS.
- TLS: доверенный/недоверенный сертификат, hostname mismatch, переопределённый default context хоста — PASS.
- Продолжение после таймаута сохраняет tool results и не повторяет инструменты — PASS.

## Настоящий запрос к LLM

После явного согласия пользователя выполнен ровно один технический запрос «Ответь одним словом: OK.» к `https://api.timeweb.ai/v1` с ключом из настроек STE. Использован Python 3.5.7 STE и исправленный `completion` с SSE и проверкой TLS. Провайдер вернул `OK` за **2.67 секунды**, tool calls отсутствовали. Переписка, ТЗ и модели не отправлялись. Ключ не записывался в исходники или лог.

Первоначальная попытка сетевого теста была отклонена автоматической проверкой до запуска; после согласия выполнен один разрешённый запрос. Успех подтверждает реальное подключение и обработку ответа. Скорость и результат полного сценария с моделью и ТЗ требуют отдельного рабочего прогона.
