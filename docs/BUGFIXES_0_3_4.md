# STE Assistant 0.3.4 — ложное устаревание нарезки

В истории пользовательского запуска 0.3.3 экспорт сначала завершался ошибкой
«Модель или настройки изменились во время экспорта», затем «completed slice
is stale…», а следующий вызов — «G-code requires a newly completed slice
generation». В get_scene были камера 3d, стол, тени/предпросмотр и камеры snapshot.

Причина: _scene_nodes возвращал все дочерние узлы сцены. Штатный Snapshot.snapshot
STE 7.10 создаёт Camera('snapshot', root) при каждом экспорте и не убирает её
из root. Собственная проверка экспорта поэтому обнаруживала «новую модель».
Обработка предпросмотра слоёв также может добавлять служебные узлы после Done.

Теперь нативные объекты выбираются по isSliceable + getMeshData (как
StartSliceJob), плюс группы isGroup. Камеры, стол, тени и предпросмотр не
попадают в get_scene, список редактируемых объектов, проверку пустой сцены,
снимок состояния нарезки и список узлов для сохранения проекта. Имена для
фильтрации не используются: настоящая деталь с именем snapshot сохраняется.

Снимок состояния моделей сортируется по id, не учитывает отображаемое имя
и включает мировую матрицу преобразования. Переименование и порядок обхода
сцены не меняют результат нарезки; реальный поворот/перенос, изменение модели,
настроек, G-code или стола по-прежнему требуют новой нарезки. Причина отказа
сообщается по-русски и сохраняется при повторной попытке экспорта.

Проверки: tests/test_scene_models.py воспроизводит добавление snapshot во
время каждого экспорта, поздний предпросмотр, движение камеры, изменение
порядка/имени, настоящую правку модели и повторный отказ с сохранением причины.
Обновлён tools/host_export_regression.py: настоящий GCodeWriter + декоратор
потоков STE, настоящие SceneNode, Camera, MeshData, SliceableObjectDecorator,
LayerDataDecorator. Два последовательных экспорта добавляют Camera('snapshot')
и сохраняют актуальность нарезки; перенос настоящей детали делает её устаревшей.
Отрисовка OpenGL и метаданные writer в этой изолированной проверке заменены
фикстурами. Сцена работающего пользовательского STE не изменяется.
